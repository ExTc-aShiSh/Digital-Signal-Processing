# Digital Signal Processing (DSP) Lab

This repository contains MATLAB implementations and analytical scripts for **Digital Signal Processing (DSP) Laboratory** experiments.

---

## Academic Context

This repository is created and maintained as part of my **academic learning curriculum**. It serves as a practical record of laboratory experiments, algorithm implementations, and signal visualization techniques in DSP.

> **Note:** This repository is actively maintained and will be continuously updated with new code, analysis, and laboratory experiments as I progress further in my coursework.

---



## Requirements

To run the MATLAB scripts in this repository:

* **MATLAB** (R2020b or newer recommended)
OR
* **GNU Octave** (free and open-source MATLAB alternative)
OR
* **MATLAB ONLINE**

---

## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/ExTc-aShiSh/Digital-Signal-Processing.git
   ```
2. Navigate to the desired topic directory in MATLAB.
3. Run the target `.m` script directly from the MATLAB Editor or Command Window.
